# EduBot Question Bank — St. Anthony's College, Shillong

## 1. Purpose

This file contains a comprehensive set of realistic user questions, written from the perspective of prospective students, current students, parents, guardians, and visitors of St. Anthony's College, Shillong. The questions are intended for testing EduBot's:

- **Retrieval accuracy** — does it pull the correct facts from official uploaded/crawled sources?
- **Source grounding** — does it answer only from official college resources, not invented knowledge?
- **Clarification handling** — does it ask follow-up questions when a query is ambiguous?
- **Formatting** — does it produce paragraphs, lists, tables, or numbered steps appropriately?
- **Freshness prioritization** — does it prefer the most current/authoritative source when documents conflict?
- **Hallucination prevention** — does it correctly refuse to answer when information does not exist in the official corpus?

No answers are provided in this file. No college facts, names, dates, fees, or policies are assumed or hardcoded — these questions are prompts only, to be tested against EduBot's actual retrieval pipeline.
